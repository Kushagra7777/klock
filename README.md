# KLOCK - AO Web Activity Tracker

## Overview

This project is designed to **track user activity on a web page (as of now)**, gather relevant web context, and use that data to improve user experience through **`ao_core`**.

The main idea is to help the agent learn how users behave by tracking how they use the site. Like where they cluck, what they type, or how they move mouse. Agent learns over time and make good recommendations.

---

## Goals

-  Track user interactions (clicks, mouse movements, keypresses)
-  Extract page context (button labels, dropdown selections, etc.)
-  Send collected data to a Python backend
-  Use `ao_core` to:
  - Learn from user patterns
  - Adapt the AO agent accordingly
  - Give real time recommendations 
  - And if user get stuck, it can even show external links of how to solve an issue (Still an idea, altough this whole project is an idea, but idea in an idia)
-  Improve user experience over time based on usage
